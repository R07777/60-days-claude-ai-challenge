# Day 20 - Face Puzzle Game

## Overview

Built an interactive Face Puzzle Game using HTML, CSS, and JavaScript with webcam integration.

## Features Implemented

* Webcam access using getUserMedia()
* Live camera preview
* Photo capture functionality
* Puzzle generation from captured image
* Difficulty levels: 3×3, 4×4, and 5×5
* Drag and drop puzzle controls
* Touch gesture support for mobile devices
* Timer and move counter
* Correct piece tracking
* Win detection system
* Local leaderboard using localStorage
* Responsive design for desktop and mobile

## Key Learnings

* Learned how browser camera APIs work.
* Implemented image processing and puzzle generation.
* Used drag-and-drop and touch events for interaction.
* Stored game records using localStorage.
* Built a responsive browser-based game without frameworks.

## Technologies Used

* HTML5
* CSS3
* JavaScript (Vanilla JS)
* Canvas API
* getUserMedia API
* LocalStorage

## Outcome

Successfully developed and tested a Face Puzzle Game with camera integration, puzzle mechanics, timer tracking, and leaderboard functionality.
