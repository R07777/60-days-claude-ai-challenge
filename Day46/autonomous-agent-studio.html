    How the stop-check governs the loop
    
      
    
        Every round, Evaluator scores the current draft across four dimensions, Critic explains
        what's still wrong and why, and Memory Manager distills a short note that both agents inherit next round.
        Before Improver is ever called, three checks run in a fixed order: plateau (score gained less than the
        configured delta for two consecutive rounds), threshold (the average score crossed your target), and a hard iteration
        cap as a pure safety fallback. The first check that fires ends the loop and branches execution to Final Reviewer;
        if none fire, Improver rewrites the draft using this round's evaluation, critique, and memory, and the loop repeats with no
        pre-set number of rounds.
