# Day 33 – Media Integrity Analyzer

## Overview
Today I built and explored the **Media Integrity Analyzer**, an interactive web application designed to improve media literacy through hands-on learning. The application teaches users how to recognize misleading headlines, emotional manipulation, and biased content while encouraging critical thinking.

## What I Did
- Generated a single-file HTML application.
- Selected a preferred color theme.
- Completed the Headline Detective challenge.
- Identified exaggerated and misleading headlines.
- Reviewed rewritten fair headlines and accuracy analysis.
- Completed the Emotion Detector challenge.
- Analyzed emotional manipulation techniques.
- Observed live Media Integrity metrics.
- Reviewed the final Media Integrity Dashboard.

## Key Learnings
- Headlines can influence readers before they read the article.
- Emotional language is commonly used to increase engagement.
- Reliable information requires critical evaluation of sources.
- Neutral wording reduces bias and improves credibility.
- Media literacy helps make informed decisions online.
