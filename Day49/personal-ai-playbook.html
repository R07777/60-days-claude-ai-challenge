🧭 What is the Personal AI Playbook?

This is a self-contained toolkit for turning the way you already use AI into reusable, editable systems — instead of retyping context every time. It stores everything locally in this browser (no servers, no accounts). There are three things you can do here:

📚 Workflow LibraryReady-made, editable prompt templates organized by what you actually do: coding, career, startup, learning.
✦ Prompt BuilderAssemble a prompt from labeled building blocks (role, objective, constraints…) with a live preview — so nothing important gets left out.
↻ Loop BuilderTurn any prompt into a self-checking, iterating "loop prompt" — useful for tools like Claude Code that can run multiple passes on their own.

    What is this?

    A quick tour of the Personal AI Playbook.

    Instead of re-explaining your context to an AI every time, this tool stores reusable AI workflow systems: editable templates with clearly labeled fill-in variables, organized by what you actually use AI for. Everything lives in this browser's local storage — nothing is sent anywhere.

    • Dashboard — overview, stats, and quick jumps into each category.
    • Workflow Library (Coding, Career, Startup, Learning) — ready-made templates you fill in and copy.
    • Prompt Builder — assemble a prompt piece by piece from labeled blocks (role, objective, constraints, etc.) with a live preview.
    • Loop Builder — turn a prompt into a self-evaluating, iterating loop with explicit stop conditions and safety rules.
    • My Workflows — everything you've favorited or built yourself.

    Your workflows, favorites, and builder drafts are saved to this browser only (localStorage). Use Export library to back them up as a JSON file, or move them to another browser with Import library.
