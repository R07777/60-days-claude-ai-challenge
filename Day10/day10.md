# Day 10 - Personal Portfolio Website

## Objective

Learn how AI can generate a complete personal portfolio website using a single prompt.

## Project

Created a modern personal portfolio website using Claude AI.

The portfolio showcases personal information, technical skills, projects, achievements, certifications, and contact details in a professional and responsive design.

## Features

* Hero Section
* About Me Section
* Skills Showcase
* Project Cards
* Achievements & Certifications
* Contact Section
* Dark/Light Mode Toggle
* Mobile Responsive Design
* Smooth Scrolling
* Social Media Links
* Modern UI Design

## Technologies Used

* HTML
* Tailwind CSS (CDN)
* JavaScript

## Files Included

* portfolio.html
* portfolio.jpg
* rishi.jpg

## Key Learnings

* AI can generate complete portfolio websites with a single prompt.
* Personal branding is important for students and developers.
* Tailwind CSS helps create modern responsive designs quickly.
* Well-structured prompts produce professional website layouts.
* AI can significantly accelerate frontend development.

## Outcome

Successfully generated and tested a complete personal portfolio website using Claude AI and explored how AI can simplify website development and personal branding.
