How this was researched ▸

Sourcing approach

Every price, benchmark, and battery figure below comes from a named, citable source: manufacturer spec pages (Apple, Lenovo product listings) and independent review outlets (Tom's Guide, Tom's Hardware, Laptop Mag, Windows Central, PCWorld, XDA Developers, Notebookcheck) plus benchmark aggregators that compile Geekbench Browser submissions (NanoReview, CPU-Monkey). No number in this tool was invented or estimated by the assistant.

Where each criterion came from

  • Price — manufacturer or review-site listed starting price for the base or as-reviewed configuration named in the spec table.
  • Performance — Geekbench 6 multi-core CPU score, cross-referenced against NanoReview's benchmark database, which aggregates real Geekbench Browser submissions for each chip.
  • Battery life — the reviewer's own tested runtime (continuous Wi-Fi web browsing or PCMark 10 Modern Office rundown), not a manufacturer marketing claim, wherever a lab test was available.
  • Display quality — raw resolution, refresh rate, and peak brightness are sourced facts. The single 0–100 "Display Quality" score is a derived composite: 40% normalized pixel count + 30% normalized refresh rate + 30% normalized brightness, computed in this tool rather than published anywhere. It is flagged as derived throughout.
  • Portability — measured laptop weight in pounds, inverted so lighter scores higher.
  • Memory & Storage — base-configuration RAM and SSD capacity as sold, averaged as two independently normalized sourced numbers (not a single published composite).

Conflicts encountered and how they were resolved

Dell XPS 13 9350 — battery life varies drastically by panel Notebookcheck measured 20.5 hours of Wi-Fi web browsing on the base FHD+ (1920×1200, 120Hz) configuration, but multiple reviewers note the optional 2.8K OLED panel draws meaningfully more power. This tool uses the tested FHD+ figure since that's the base/cheapest configuration being compared, and flags the OLED tradeoff in the spec table note.
ASUS ROG Zephyrus G14 — battery framed inconsistently across reviewers Tom's Guide and Windows Central both describe the G14's battery life qualitatively as "middling" for productivity, while a lab-tested PCMark 10 Modern Office score of 5 hours 27 minutes gives a concrete number. This tool uses the lab-tested figure for consistency with the other three laptops, all of which are scored on measured runtimes rather than marketing claims.
Lenovo ThinkPad X1 Carbon Gen 12 — price swings widely with configuration and promo codes Lenovo's list price for the reviewed 16GB/512GB OLED configuration was $2,263 (Tom's Hardware), but Lenovo frequently runs steep coupon discounts (seen as low as ~$1,649 in Notebookcheck deal coverage) and a lower-cost non-touch IPS configuration also exists. This tool uses the as-reviewed list price for an apples-to-apples comparison and calls out in the table that street pricing is often meaningfully lower.

Limitations

These are 2024-generation models (MacBook Air M3, Dell XPS 13 9350 "Lunar Lake," ASUS ROG Zephyrus G14 2024, Lenovo ThinkPad X1 Carbon Gen 12), the specific configurations named in the spec table, and battery/benchmark results reflect each reviewer's individual test unit and methodology, which can vary. Treat this as a well-sourced starting point for a decision, not a substitute for checking current retailer pricing before purchase.
