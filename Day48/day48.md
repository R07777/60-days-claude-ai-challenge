## 📖 Overview
Today I built **Compare & Decide Builder**, an AI-powered decision support application that compares multiple laptop options using real research, adjustable criteria weights, and live ranking updates.

The application helps developers and professionals confidently choose the best laptop by combining verified specifications with trusted review sources.

- Live comparison dashboard
- Adjustable criteria weights
- Real-time ranking updates
- Multi-criteria decision matrix
- Professional scoring system
- Research-backed comparison
- Sources & citations panel
- "How this was researched" section
- Responsive premium UI
- Interactive charts & score visualization
- Dark mode interface
- Single-file HTML application
