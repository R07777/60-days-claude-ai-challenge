# Day 37 – Task Compass

## Overview
Today I built and explored **Task Compass**, an interactive workplace simulation designed to teach how work flows through real organizations. The application focuses on ownership, delegation, collaboration, and workflow thinking using engaging drag-and-drop activities.

## What I Learned
- How organizations assign ownership for different tasks.
- The importance of proper task routing between teams.
- Why collaboration is essential for solving complex workplace challenges.
- How multiple departments contribute to successful project execution.
- Real-world organizational workflows through interactive simulations.

## Features
- Offline single-file HTML application
- Premium dark UI with glassmorphism
- Drag-and-drop interactions
- Three interactive learning stages
- Organizational Thinking Dashboard
- Responsive design
- Replay with different workplace types

## Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## Key Takeaway
Understanding how responsibilities flow across teams is just as important as technical skills. Successful organizations rely on collaboration, clear ownership, and effective communication.
