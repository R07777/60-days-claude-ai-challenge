# Day 6 - ATS Resume Optimization

## Objective
Learn how AI can create and optimize resumes for ATS systems and recruiter readability.

## Process
I did not have an existing resume. I provided my education, projects, skills, certifications, and target role to Claude AI.

Claude generated a professional ATS-friendly one-page resume and optimized it for AI/ML Engineer, Full Stack Developer, and Software Engineer roles.

## ATS Result

Previous Score: N/A (No Existing Resume)

Optimized Score: 87/100

## Key Improvements Suggested

- Added a professional summary
- Organized skills into categories
- Used ATS-friendly section headings
- Improved project descriptions
- Included relevant certifications
- Optimized resume structure for recruiter readability

## Key Learnings

1. ATS-friendly resumes should use simple formatting.
2. Keywords play an important role in resume screening.
3. Projects and certifications should be relevant to the target role.
4. AI can help create professional resumes quickly.
5. A one-page resume is ideal for students and freshers.
