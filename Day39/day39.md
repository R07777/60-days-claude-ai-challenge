# Day 39 – PDF Splitter & Merger

## Overview
Today I built **PDF Splitter & Merger**, a premium browser-based PDF utility that allows users to split, merge, preview, and organize PDF documents entirely on the client side without uploading files to external servers.

## What I Learned
- Client-side PDF processing using JavaScript
- Building responsive drag-and-drop interfaces
- Working with PDF previews and page rendering
- Implementing file validation and error handling
- Creating modern UI/UX with smooth interactions

## Features
- PDF Splitter
- PDF Merger
- Drag & Drop Upload
- Page Thumbnail Preview
- Split by Page Numbers
- Split by Custom Ranges
- Split Every N Pages
- Extract Selected Pages
- Merge Multiple PDFs
- Drag-and-Drop File Reordering
- Live Page Count & Output Summary
- Download Processed PDFs
- Dark Mode
- Responsive Design
- Loading Animations
- Accessibility Support
- Keyboard Shortcuts
- Offline Processing (After Initial Load)

## Technologies Used
- HTML5
- CSS3
- JavaScript
- Client-side PDF Libraries

## Key Takeaway
This project demonstrated how powerful browser-based applications can be by processing PDF files locally, improving privacy while delivering a smooth and professional user experience.
