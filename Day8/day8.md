# Day 8 - Personal Environmental Health Analyzer

## Objective

Learn how to create a complete interactive dashboard application using Claude Artifacts and environmental data.

## Tool Used

Claude AI

## Project

### Personal Environmental Health Analyzer

A responsive environmental dashboard that analyzes air quality metrics and presents them through interactive visualizations.

## Features

* Environmental Health Score
* AQI Analysis Dashboard
* Highest and Lowest AQI Cities
* AQI Comparison Charts
* PM2.5 Analysis
* PM10 Analysis
* AQI Distribution Visualization
* City Ranking Dashboard
* Interactive Filters
* Health Risk Insights
* Personalized Recommendations

## Dashboard Screenshot

![Environmental Health Analyzer](dashboard_screenshot.png)

## Key Learnings

* Claude can generate complete HTML dashboard applications.
* Interactive data visualization improves analysis and understanding.
* Environmental data can be transformed into meaningful insights using AI.
* Dashboards help users quickly identify pollution trends and health risks.
* Claude Artifacts can be used to build shareable web applications without writing extensive frontend code.

Successfully generated and tested a fully interactive Environmental Health Analyzer dashboard using Claude Artifacts and environmental data visualization techniques.
