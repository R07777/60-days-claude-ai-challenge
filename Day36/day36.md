# Day 36 – Cognitive Pattern Explorer

## 📌 Project Overview
Today I built **Cognitive Pattern Explorer**, a psychology-inspired interactive web application that helps users explore different thinking tendencies through engaging scenarios and reflection-based activities.

## 🚀 Features
- Calm Mode & Stress Mode
- Interactive Thinking Style Discovery
- Drag & Drop Priority Challenges
- Thinking Timeline Activities
- Personalized Reflection Journal
- Thinking Pattern Breakdown
- Responsive Offline Design
- Smooth Animations & Progress Tracking

## 🛠️ Technologies Used
- HTML5
- CSS3
- Vanilla JavaScript

## 🎯 What I Learned
- Designing interactive educational experiences
- Implementing reusable drag-and-drop components
- Creating personalized reflection systems
- Improving responsive UI/UX design
- Building offline-first web applications
