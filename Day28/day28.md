# Day 28 – Hospital Admission Readiness Simulator

## Overview

Today I built a Hospital Admission Readiness Simulator using HTML, Tailwind CSS, and Vanilla JavaScript. The simulator models a hospital admission workflow by allowing users to configure patient admission details and evaluate admission readiness.

## Features

* Provider and physician setup
* Diagnosis and admission type selection
* Prior Authorization workflow
* Insurance and documentation verification
* Bed assignment simulation
* Admission readiness score
* Risk tracking
* Care coordination cards
* Governance snapshot
* Final admission decision

## What I Learned

* Designing healthcare workflow simulations
* Managing multiple workflow states
* Implementing readiness scoring logic
* Creating responsive healthcare interfaces
* Improving UI with interactive status updates
