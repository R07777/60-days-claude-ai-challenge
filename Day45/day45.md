# Day 45 – Decision Report Dashboard

## 📌 Project

**Decision Report Dashboard**

## 🎯 Objective

Built an interactive decision-making dashboard that helps users analyze difficult choices through a structured workflow. The application transforms user responses into an organized report featuring decision analysis, scoring, risk assessment, and action planning.

## 🚀 Features

* Interactive decision interview
* Decision Matrix with animated score bars
* Case-for-each-option analysis
* Assumption & Cognitive Bias detection
* Premortem risk analysis
* 7-Day Decision Test Plan
* Final Verdict with reasoning
* Shareable summary cards
* Premium responsive dark UI
* Single-file offline HTML application

## 🛠 Technologies Used

* HTML5
* CSS3
* Vanilla JavaScript

## 📚 Key Learnings

* Designing structured decision-support interfaces
* Visualizing comparisons using animated dashboards
* Organizing complex information into clear UI sections
* Building responsive layouts with reusable components
* Improving user experience through progressive workflows
